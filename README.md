## 🎨 Editorial & Anti-Slop Design Philosophy

This portfolio intentionally departs from common "AI-generated template cliches" (AI Slop) characterized by eye-straining pitch-black canvas, neon electric cyan accents, and superfluous looping animations.

1. **Subtle & Restful Surface Hierarchy:**
   - Deep charcoal background (`#0e1015`) layered with tiered slate cards (`#15181f` and `#1c202a`).
   - Calming royal slate blue (`#4b85db`) used intentionally as an interactive accent.
2. **Authentic Imagery & Content:**
   - Removed artificial grayscale filters and fake lens flares; restored full authentic color profiles to photography.
   - Removed fake glowing borders (`border-l-2`) and distracting pulsing indicators (`animate-pulse`).
3. **High Accessibility & Touch Targets:**
   - Strict WCAG AA contrast compliance for text and UI controls.
   - Mobile navigation and interactive elements strictly conform to minimum 44×44px touch targets.
4. **Tactile Micro-interactions:**
   - Subtle hover states and physical `active:scale-[0.98]` feedback for buttons and cards.

## 💻 Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v20+ recommended) or [Bun](https://bun.sh/) (v1.1+)

### 1. Clone the repository
```bash
git clone https://github.com/Wilhelm-art/portofolio-adit.git
cd portofolio-adit
```

### 2. Install dependencies
```bash
bun install
# or
npm install
```

### 3. Run development server
```bash
bun run dev
# or
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
bun run build
# or
npm run build
```
