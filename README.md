## ✨ Features
- **Modern Tech Stack:** Built with React 19, Vite, and TypeScript.
- **Styling & Animations:** Tailwind CSS v4 for styling and Framer Motion for smooth, tactical UI animations.
- **Internationalization (i18n):** Full support for multiple languages (English & Indonesian).
- **SEO Optimized:** Helmet Async for metadata and proper semantic HTML.
- **Responsive Design:** Mobile-first approach ensuring a great experience across all devices.
- **Performance Focused:** Fast load times with Vite and optimized asset delivery.

## 💻 Run Locally

**Prerequisites:** Node.js & Bun (Recommended)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Wilhelm-art/portofolio-adit.git
   cd portofolio-adit
   ```

2. **Install dependencies:**
   ```bash
   bun install
   # or npm install
   ```

3. **Run the development server:**
   ```bash
   bun run dev
   # or npm run dev
   ```
   *The app will be available at `http://localhost:3000`*

4. **Build for production:**
   ```bash
   bun run build
   # or npm run build
   ```
